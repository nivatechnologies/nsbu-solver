# nsbu-solver

Public NSBU Solver library with geometry, half-spectrum layouts, exact dyadic
clocks, checked epochs, resource reservations and independently owned from-rest
state buffers. Spectral operators provide normalized transforms, strict-band
three-halves transfers, projection, curl, rotational acceleration and physical
pressure. Cox–Matthews and Hochbruck–Ostermann coefficients/stages, bounded full/two-half attempts, provider
accounting and single-use transactional commits are implemented. Numerical CLI
commands are supplied by the companion CLI for the bounded smooth diagnostic;
concentrating-trajectory qualification remains in progress. Licensed under Apache-2.0, with no
private Niva dependency.

`verification::protocol::FrozenProtocol` borrows admitted numerical policies and
exact time/reconstruction manifests. Its canonical artifact and SHA-256 identity
include all effective channel rules and geometry; bounded review creation reuses
those same immutable inputs. The root `docs/PROTOCOL_FORMAT.md` specifies byte
order, field sizes, resource admission, independent format fixtures and remaining
benchmark/provenance obligations. This generic identity component does not issue
a PDE-window acceptance status.

The built-in CPU FFT supports lengths at most 1024 with only factors 2 and 3.
Both retained and padded layouts must fit that profile. Planning reserves owned
roots and scratch before allocation; transforms and operator evaluations do not
allocate. Callers must separately budget input/output and allocator overhead.
Operator outputs are scratch and become invalid on error; input state is immutable.

Independent diagnostics provide full-band norms, conservative double-grid pressure
and residuals, accepted-history Hermite reconstruction, balance measurements,
sampled velocity/vorticity maxima, directional tails and spectrum-integrity reports.
Local error statistics retain explicit missing samples and declared relative floors.
These measurements do not accept a PDE convergence window or provide rigorous
continuous-time enclosures. Diagnostic storage has its own preflight requirements.
