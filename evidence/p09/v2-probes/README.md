all 48 branch/time three-node Hermite geometries before allocation and admits the
six owners, full value/derivative scratch, ten pair comparisons, report metadata
and finite work.  The default exact-v2 family, runtime CLI and checkpoints remain
unchanged.

N=4/8/12 and h=64/32/16 CM/HO schedule.  It checks exact accepted-node and current
state clocks, immutable family/probe identity, early-history streaming, endpoint
identity and complete transactional publication.  All value and derivative pair
reports are checked by a separate full-complex integer-mode reducer.  Every final
branch state, history and work ledger equals a separately evolved reconstructed
owner bit for bit.

quintic Hermite weights.  Its node derivatives are separately assembled from
fresh `V2Force` and `ConservativeWorkspace` evaluations.  This control is
independent of the observer's stored nodes but reuses production PDE operators;
it is not a wholly independent PDE-operator oracle.

rejected branch publishes no partial fields, becomes terminal and preserves its
physical words, clock, work ledger and charged report work on a refused retry.
