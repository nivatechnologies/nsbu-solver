# Standalone W3 layout-768 controls

This harness owns only prospective controls. `preflight` allocates no numerical grid and reports the currently closed W3 admission. `force` and `rhs` each require a distinct environment gate, run sequentially, and have not been executed.

`force` compares a retained-N512/M768 serial force owner to a forward W3 owner. `rhs` compares a retained-N512/padded-768 serial RHS to a bidirectional W3 RHS driven by a fixed zero-storage force fixture. Both require exact W3 identities, one-byte-under admission inside the constructors, complete coefficient-bit equality, matching work/consumption, and three allocation-free repeated evaluations.

The control is non-admissible until a separately reviewed 768-only production admission is present. It has no observer, trajectory, archive, resume, or qualification path.
