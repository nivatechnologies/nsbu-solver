## P06 responsibility and measurement review

The fixed runner owns scheduling policy and reports the last committed state;
it borrows preflighted workspaces and delegates numerical work and token commits
to their existing interfaces. The smooth prescribed source supplies continuum
forcing coefficients independently of the integrated state. Reference comparison
occurs in test code after evolution. Neither source can assign an analytical
reference to the state. Run configuration is validated before the first attempt,
and a later failure preserves earlier successful commits.

All maintained Rust implementation and test files remain in the static-analysis,
duplication and complete line/branch coverage scopes. The complete test suite runs
the smooth spatial family and independent concentrating trajectory comparison.
Mutation reruns skip only those two long studies using their exact test names;
they retain the smooth temporal convergence test and all focused force, Fourier,
clock, budget, kernel and transaction tests. No production source is excluded
from mutation generation. The final report must account for every generated
mutant, with zero surviving or timed-out mutants before package completion.

The initial smooth spatial family uses a band-limited manufactured solution.
Its full-fine-band comparisons test grid consistency and approach a temporal
error plateau; they do not measure a general spatial convergence order. Fourth
order temporal convergence on this case is separate from stiff order validation
and the concentrating benchmark's unresolved spatial and force sampling errors.

The 80/120-digit concentrating fixtures are generated by the preserved Python
reference implementation, with no production FFT or stage kernel used as an
oracle. Agreement on an N=4 discrete trajectory is an arithmetic/kernel check,
not an accepted PDE window. The exact-v2 pilot retains its large tracking errors.
