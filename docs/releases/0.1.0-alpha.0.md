NSBU Solver is an Apache-2.0 Rust library and CLI for periodic 3D incompressible Navier–Stokes experiments with positive viscosity and prescribed forcing.

This diagnostic alpha provides Fourier pseudospectral operators, CM/HO exponential time integration, independent from-rest trajectories, bounded transactional attempts, resource preflight, exact tick clocks, and checkpoint/resume. The `similarity-mms-v2` benchmark uses manufactured forcing; its analytical reference never replaces the integrated state.

**Scientific limits:** zero accepted concentrating PDE windows. The default N=4/M=4 run is a small-grid diagnostic, with unresolved spatial/force convergence. This release does not prove blow-up, resolve the Millennium problem, or reproduce the cited manuscript's full construction. Scientific qualification continues separately.

Download the Linux x86_64 GNU archive and its `.sha256` asset below. Verify the archive, extract it, then run these commands inside its directory:

```sh
sha256sum -c SHA256SUMS
./bin/nsbu v2 --dry-run
./bin/nsbu v2
./bin/nsbu v2 --method ho
./bin/nsbu v2 --method ho --checkpoint run.chk --checkpoint-after 16
./bin/nsbu resume-v2 --method ho --checkpoint run.chk
```

The binary was built on Ubuntu 24.04; its manifest records GLIBC_2.35 as the highest required symbol version. Other platforms require source builds and remain unverified. Python is needed for repository/reference verification, not for running the binary.

## Research context and contributions

OpenAI reports a forced Navier–Stokes breakdown proof in its [research announcement](https://openai.com/index/navier-stokes-solution/). NSBU is an independent numerical project for a different manufactured case; it neither certifies that proof nor resolves its complete cascade. The [README](https://github.com/nivatechnologies/nsbu-solver#readme) explains the relation to the Millennium problem and to Euler mechanism visualizations, and separates implemented functionality from remaining work.

We are actively looking for contributors in numerical analysis, spectral methods, Rust performance, independent verification, documentation and scientific visualization. See [CONTRIBUTING.md](https://github.com/nivatechnologies/nsbu-solver/blob/main/CONTRIBUTING.md). The next goals are complete concentrating diagnostics, independent refinement/error studies, scientific lineage and the first accepted finite PDE window. Release timing depends on completed checks.
